## 4. 优先级与冲突处理

1. **能力契约**：按 `AGENTS.md` §7，以设计文档 FR 与 `kp` CLI 实际行为为准；`skill/SKILL.md` 是 Agent 契约，发现不一致立刻修正。
2. **FR-15 缓存**：以 `kafka-pilot-本地缓存详细设计.md` 为准；`03-功能需求-审计与配置.md` 中的 FR-15 段落是 v1.4 历史草稿，仅作溯源，不用于实现。
3. **界面**：以 `web/src` 业务前端为唯一实现基线（`05-界面设计.md` §10.4）。
4. **历史原文**：`archive/` 快照只用于核对「拆分有没有丢内容」，不参与后续维护，也不要在其中追加变更。
