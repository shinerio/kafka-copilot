阅读说明：本草图为静态高保真线框，交互以 Fluent UI React v9 组件实现为准（DataGrid 虚拟滚动支撑 5000 条、ProgressRing / Bar、Dialog、CommandBar）。紫色圆点为设计标注，对应各屏下方图例。
全局约束回顾：① CLI 与客户端共用同一内核用例层，双端能力一致；② AI 观测区仅 GET + SSE 只读通道，服务端不暴露写接口；③ operations 行仅存最终结果统计、单条 < 4KB、不含消息体，scan 命中内容以有界快照（≤100 条 / 1MB）独立存储；④ 扫描 direct assign、不提交 offset；⑤ 本地单机工具，工具自身无认证鉴权（Kafka 连接的 SASL / TLS 认证属 profile 配置）；⑥ 主题 / 强调色 / 密度跟随系统并可调。
